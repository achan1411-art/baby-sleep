☁️ Cloud sync setup

Follow these steps once. After that your history saves automatically to Google Sheets and syncs across every device — phone, tablet, computer, anywhere.

1
Create your Google Sheet
Go to sheets.google.com and create a new blank spreadsheet. Name it Baby Sleep History. Leave it open — you'll need it in step 2.
2
Add the sync script to your Sheet
In your Sheet, click Extensions → Apps Script. Delete any code in the editor and paste in the code below, then click Save (the floppy disk icon).
3
Deploy the script as a web app
In the Apps Script editor, click Deploy → New deployment. Set type to Web app, set "Who has access" to Anyone, then click Deploy. Copy the Web app URL it gives you.
4
Paste your Web app URL here
Paste the URL from step 3 below and click Connect. That's it — your history will sync to Google Sheets automatically from now on.
5
Host on GitHub so it opens from any device
  1. Go to github.com and create a free account
  2. Click the + icon → New repository. Name it baby-sleep, set it to Public, click Create
  3. Click Add file → Upload files and upload baby_sleep_scheduler.html — rename it to index.html when uploading
  4. Click Settings → Pages, set Source to main branch, click Save
  5. Your app URL will be https://YOUR-USERNAME.github.io/baby-sleep — bookmark this on your phone and computer!
